### 情感分类任务
情感分类任务（Sentiment Classification Task）是自然语言处理（NLP）中的一个重要任务，旨在识别和分类文本中表达的情感倾向。通常，这些情感倾向可以分为正面、负面和中性，或者更细分的类别如高兴、愤怒、悲伤等。情感分类广泛应用于产品评价分析、社交媒体监测、品牌声誉管理等领域

任务本质：将文本依据其蕴含情感分成不同类别
